### [Discipline OS](https://github.com/pratiksijapati/discipline-os)
A mobile-first productivity app that turns a day's schedule, tasks, habits, workouts and goals into a daily discipline score.

Tech: `React` `TypeScript` `Django REST Framework` `PostgreSQL` `JWT` `PWA`
Links: [Live demo](https://discipline-os-omega.vercel.app) · [Code](https://github.com/pratiksijapati/discipline-os)

Django REST Framework API split into 10 domain apps with 134 backend tests, plus an installable, offline-capable PWA with Web Push reminders. Deployed on Vercel, Render and Neon.

### [Career Navigator](https://github.com/pratiksijapati/ai-career-recommendation-system)
Recommends careers to students from academic scores, skills and interests: Domain → Role → Specialization → Skill Gap → Roadmap.

Tech: `Python` `FastAPI` `scikit-learn` `React` `Vite`
Links: [Code](https://github.com/pratiksijapati/ai-career-recommendation-system)

Random Forest models for domain and role, Nearest Neighbors for specialization, blended with interest and skill fit in a weighted scoring module that explains each recommendation.
